# Italian outlet distillation audit — 2026-07-02 (issues #89 / #95, meta #80)

Full-catalog audit of every outlet host in the Italy region of
`RSSFeedCatalog` (48 feeds → 19 distinct outlet hosts). Two articles
per outlet (three for ANSA: cronaca + topnews sections) were fetched
live on 2026-07-02 with the production `ArticlePageClient` headers and
committed here as `<slug>__<host>__<lang>.html` (+ `.url` provenance).
Each page was run through the full distillation pipeline by
`MercuryTests/ItalianOutletAuditHarness.swift`; per-page profiles
(word count, chrome survivors, raw paywall markers, head/tail
excerpts) live in `_snapshots/`.

## Verdict criteria

* **clean** — body-only output on both pages; no consent/cookie,
  paywall CTA, link lists, nav/share/newsletter chrome in the
  distilled text.
* **fixed** — chrome leaked on the initial run; fixed in this branch
  via a per-outlet entry in `ArticleOutletExtractionRules.json` and
  re-verified clean.
* **paywalled → classifier** — the page ships no readable body
  (subscriber-only teaser). Handled by `ArticlePaywallClassifier`
  (#95): the article stays un-enriched and the reader shows the RSS
  item summary. Outlet kept in catalog.

## Disposition

* **Removed / replaced: none.** Every Italy-region outlet produces
  body-only output after the rule fixes; the two paywalled outlets
  (Repubblica premium, The Local members-only) degrade gracefully to
  the RSS summary via the #95 classifier instead of surfacing CTA
  copy, and both also publish free articles that distill fully.
* Rule additions/changes in this branch: tgcom24, internazionale,
  thelocal (commit a5b1771); fanpage, gazzetta, ilfatto, ilgiornale,
  ilsole24ore (commit 6317479).
* Regression pins: every fixed outlet's chrome is a `bannedSubstrings`
  entry on its committed fixture in
  `MercuryTests/ItalianDistillationFixturesTests.swift`.

## Reproducing

Drop pages as `<slug>__<host>__<lang>.html` in this directory and run:

```bash
xcodebuild test -project Mercury/Mercury.xcodeproj -scheme Mercury \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.3.1' \
  -only-testing:MercuryTests/ItalianOutletAuditHarness -quiet
```
