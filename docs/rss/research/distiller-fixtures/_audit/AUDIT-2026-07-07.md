# Italian outlet distillation audit — 2026-07-07 (issue #98, meta #80, classifier #95)

Live-corpus audit of the full distillation pipeline **after** the
Mozilla Readability stage (#98): JSON-LD `articleBody` fast path →
sanitizer → per-outlet rule → hidden-WKWebView Readability →
terminator truncation → boilerplate remover → locale stripper →
paywalled-teaser classifier (#95). One article per Italy-region feed
of `RSSFeedCatalog` (42 feeds; some outlets contributed a second page,
plus a third Libero blog page pulled in to chase a header leak — 57
pages total) was fetched live on 2026-07-07 with the production
`ArticlePageClient` headers and committed under `2026-07-07/` as
`<slug>__<host>__<lang>.html` (+ `.url` provenance). Each page was run
through `MercuryTests/ItalianOutletAuditHarness.swift`; per-page
profiles live in `2026-07-07/_snapshots/`.

## Verdict criteria

* **clean** — body-only output; no consent/cookie, paywall CTA, link
  lists, nav/share/newsletter or video-player chrome in the distilled
  text. Pages with no distillable body (video/photo-only pages, wire
  bulletins under the pipeline's 80-word `distilledMinimumWords`
  floor) that degrade gracefully to the RSS-summary fallback without
  emitting chrome also count as clean and carry a note.
* **fixed-via-rules** — chrome leaked on the initial run; fixed in
  this branch via `ArticleOutletExtractionRules.json` and re-verified
  clean.
* **paywalled → classifier** — the page ships no readable body
  (subscriber-only teaser). `ArticlePaywallClassifier` (#95) keeps the
  article un-enriched and the reader shows the RSS item summary.
* **removed** — outlet dropped from the catalog (none this audit).

## Disposition

* **Removed / replaced: none.** Every Italy-region outlet produces
  body-only output after the rule fixes; paywalled pages degrade
  gracefully to the RSS summary via the #95 classifier, and all three
  paywalled feeds also publish free articles that distill fully
  (repubblica-cronaca/economia/politica, the-local-italy-1).
* Rule additions in this branch: tgcom24 header selectors + linkiesta
  rule (commit 23d5372); ilgiornale `.article__toolbar` /
  `#audio-player-container` + internazionale `.print_header` (this
  commit).
* Regression pins: linkiesta-gwm-ora5 and tgcom24-video-trump-meloni
  fixtures (commit 23d5372); `intern.az/` bannedSubstring on the
  internazionale fixture (this commit). The ilgiornale fixture
  predates the outlet's text-to-speech player, so that fix is verified
  by the audit harness snapshot rather than a fixture pin.
* Short wire bulletins and video/photo-only pages intentionally fall
  below the pipeline's 80-word `distilledMinimumWords` floor and fall
  back to the RSS item summary — no chrome is surfaced.

## Reproducing

Drop pages as `<slug>__<host>__<lang>.html` in a dated
`_audit/YYYY-MM-DD/` corpus directory and run:

```bash
xcodebuild test -project Mercury/Mercury.xcodeproj -scheme Mercury \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.3.1' \
  -only-testing:MercuryTests/ItalianOutletAuditHarness -quiet
```
